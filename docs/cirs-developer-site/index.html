Quick reference

What developers usually need first

These are the recurring points that slow changes down in this repository. The microsite pages expand each of them with the actual tables and checks.

Environment truth

Confirm the active feature profile and required governance variables before you inspect runtime behavior.

Auth posture

Do not debug token or MFA behavior until you know whether the instance is local or Supabase-backed.

Owning abstraction

Conventional resources belong in the CRUD engine. Custom incident and privacy flows do not.

Validation order

Use the narrowest test or build check that can falsify the change before widening scope.

Suggested order
